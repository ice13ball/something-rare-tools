Privacy

Your files stay on your computer

Files you drop on this site are read and checked by your own browser. They are never uploaded, whichever download mode you choose.

Browser mode (default)

In this mode your own browser downloads linked files directly from the data server. Some servers do not allow this; the tool then tells you so and asks you to download the file yourself and drop it here.

Server mode

If you choose the Abyssal Claims server, it downloads public files of public records for you, and only from these known data servers:

  • opendap.iopan.pl
  • geo.iopan.pl
  • geonetwork.iopan.pl
  • zenodo.org
  • doi.pangaea.de
  • api.datacite.org
  • data.crosscite.org
  • doi.org

The server stores nothing: no files, no copies, no cache. Its log records only the host name, the status code and the size of each request, never the full address.

Analytics

Google Analytics 4 is used only if you accept it in the cookie notice. Until then nothing is sent to Google and no analytics cookies are set.

Events carry only counts (how many errors, warnings and notes), the type of input (file, Zenodo, GeoNetwork, DOI, PANGAEA or mixed) and the download mode. They never contain file names, DOIs, links or values from your data. You can change your choice at any time with “Cookie settings” in the footer.
