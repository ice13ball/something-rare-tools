Abyssal Claims Tools

Simple tools for checking marine data before it is published.

Data check

Checks marine dataset files and their metadata for coordinate, date, unit and licence problems and explains each one in plain words.

Open data check

Licence check

Compares the licence that the metadata sources of one dataset state (Zenodo, PANGAEA, GeoNetwork, DataCite), shows how each is classified and where they contradict each other.
