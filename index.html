Abyssal Claims Tools

Simple tools for checking marine data before it is published.

  • Data check

    Data files or a link to a record: coordinates, dates, units and licence, explained in plain words.

    Open

  • Licence check

    One dataset: what licence each metadata source states and where they disagree.

    Open

  • Collection review

    A whole collection: a fix list of missing, unclear or conflicting licences and empty metadata fields.

    Open
